Sorteios (Giveaways)

Usa /giveaway start no Discord para criar sorteios. Os membros clicam num botão para participar e os vencedores são anunciados automaticamente.

Comandos disponíveis:
  • /giveaway start — Inicia um novo sorteio
  • /giveaway end — Termina um sorteio antecipadamente
  • /giveaway reroll — Sorteia novos vencedores
