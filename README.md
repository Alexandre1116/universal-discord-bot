# Universal Discord Bot

A simple and self-hosted free discord bot built with Node.js, Discord.js v14, and an Express Web UI Dashboard.

## Funcionalidades Integradas
- **Mensagens de Boas-Vindas e Despedidas**: Personalizáveis via Dashboard.
- **Canais de Voz Dinâmicos**: Criação e eliminação automática de canais temporários.
- **Web UI Dashboard**: Interface para gestão do bot (Módulos, Configurações).
- **Módulos Ligar/Desligar**: Ativa e desativa componentes inteiros do bot na hora.
- **Música**: Funcionalidades de música completas com DisTube.
- **Níveis e Voice XP**: Os utilizadores ganham experiência e níveis por mensagens e por estarem em canais de voz.
- **Auto-Moderação e Auto-Respostas**: Ferramentas de controlo de chat automáticas.

## Como Iniciar

1. `npm install`
2. `npm start`
3. Acede a `http://localhost:3000` para configurar o teu Bot.
